Creating Your First Project

Before you touch any real coursework, let's set up a clean project folder the right way — the same structure you'll reuse for every assignment going forward.

  1. Create a new folder on your computer named my-first-project.
  2. Open that folder in VS Code using File → Open Folder.
  3. Inside it, create a new file named index.html.
  4. Type the following starter code into index.html: 
    <!DOCTYPE html>
<html>
<head>
  <title>My First Project</title>
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>
  5. Save the file, then right-click inside it and choose "Open with Live Server."
  6. Your browser should open automatically and display "Hello, World!"

Publishing Your Project to GitHub

Once you've built something, you'll want a record of it — and a public link to show it off. Here's how to push your first project to GitHub.

  1. Open the terminal inside VS Code (Terminal → New Terminal).
  2. Run git init to start tracking your project with Git.
  3. Run git add . to stage all your files.
  4. Run git commit -m "My first commit" to save a snapshot.
  5. Create a new repository on GitHub, then follow GitHub's instructions to push your local project to it.
  6. Refresh your GitHub repository page — your files should now appear there.

Once you're comfortable with both of these, you're ready to move on to your first real lesson.
