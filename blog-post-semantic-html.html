Why We Teach Semantic HTML Before Anything Else

August 5, 2026

It's tempting to jump straight to JavaScript frameworks. New students want to build the flashy stuff — the interactive dashboards, the animated interfaces, the things that feel like "real" development. But every strong developer we've hired started with a genuinely solid grasp of plain, semantic HTML, and here's why that foundation matters more than it seems.

Frameworks change. Structure doesn't.

The specific framework that's popular today won't be the one that's popular in five years — we've watched this cycle happen more than once. What doesn't change is that every framework, no matter how modern, still ultimately outputs HTML to the browser. A developer who understands what good structure actually looks like can pick up any framework quickly. A developer who's only ever learned a framework's shortcuts struggles the moment something breaks underneath it.

It's the foundation accessibility is built on

Screen readers, keyboard navigation, and search engines all depend on HTML that actually describes what it contains. A <button> is focusable and announced correctly by default. A <div> styled to look like a button is neither, unless you manually rebuild everything the real tag already gave you for free. Students who learn semantic HTML first build accessible habits automatically, instead of retrofitting them later.

It teaches you to think in structure, not just style

The biggest shift we see in students who start with semantic HTML is that they stop asking "how do I make this look right" and start asking "what is this, really." That question — is this a navigation, a piece of standalone content, a list of related items — is the same question that underlies good component design in every framework that follows.

By the time our students get to JavaScript frameworks, they're not learning structure and syntax at the same time. They already know what a well-structured page looks like, so they can focus entirely on how the framework moves data around. That head start is why it's the first thing we teach — not the last.
