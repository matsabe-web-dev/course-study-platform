Module 1: HTML & CSS Foundations · Lesson 1.3

Building Your First Layout

In this lesson, you'll learn how semantic HTML elements work together to structure a real page — the same foundation every website you'll ever build rests on.

Every well-built webpage starts with structure before style. In this lesson, we're focusing entirely on semantic HTML — the practice of choosing elements based on what content means, not how you want it to look. A <header> isn't just a box at the top of the page; it tells browsers, search engines, and assistive technology exactly what role that region plays.

Open your code editor and follow along. By the end of this lesson, you'll have built a simple, fully semantic one-page layout containing a header, a navigation menu, a main content area, and a footer — the exact skeleton nearly every website on the internet is built from.

Here's the basic skeleton we're building toward:

<header>
  <h1>Site Title</h1>
  <nav>...</nav>
</header>
<main>
  <p>Page content goes here.</p>
</main>
<footer>
  <p>Copyright text.</p>
</footer>

Save your file by pressing Ctrl+S, then refresh your browser to see the change.
