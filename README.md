 Course Study Platform

A multi-page website project for browsing courses, reading blog posts, and accessing student resources. Built as a hands-on coding practice project using HTML, CSS, and JavaScript.

 Pages & Structure

- index.html — Homepage
- about.html — About the platform
- contact.html — Contact page
- blog.html — Main blog listing page
- Blog posts — Individual articles, including:
  - Data analyst career story
  - Design detail walkthrough
  - Common HTML mistakes
  - Security audit notes
  - Semantic HTML guide
  - VS Code extension recommendations
- courses/ — Course-related pages
- student/— Student-facing pages/resources
- docs/ — Supporting documentation
- images/ — Image assets used across the site

Tech Used

- HTML5, CSS

Status

Work in progress — pages and content are being added and refined over time.
