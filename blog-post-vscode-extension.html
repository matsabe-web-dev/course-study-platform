The One VS Code Extension Every Beginner Should Install First

July 15, 2026

Live Server isn't optional — it's the single tool that will save you the most frustration in your first month of coding. Here's how to set it up in under two minutes.

The problem it solves

Without it, checking a change means saving your file, switching to your file browser, finding your HTML file, and reopening it — every single time. Most beginners either skip this step and only check their work occasionally, or get so tired of it that they stop testing changes as they go. Both habits slow down learning, because the fastest way to understand HTML and CSS is to see the effect of a change immediately.

What Live Server actually does

It runs a small local server and opens your project in the browser, then automatically refreshes that page every time you save a file. Change a colour, hit save, and the browser updates on its own — no switching windows, no manual refresh, no forgetting whether you're looking at the latest version.

How to set it up

  1. Open the Extensions panel in VS Code (the icon that looks like four squares in the sidebar).
  2. Search for "Live Server" and install the one by Ritwick Dey — it's the most widely used and the one we teach with.
  3. Open your project folder in VS Code, right-click your HTML file, and choose "Open with Live Server."
  4. Your browser opens automatically. From here, every saved change updates instantly.

That's the whole setup. It takes less time to install than it took to read this post — and once it's running, you'll wonder how you were coding without it.
