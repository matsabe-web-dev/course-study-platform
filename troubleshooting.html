Common Errors

My page shows a blank white screen.

This almost always means your HTML file has an error the browser can't recover from — usually a missing closing tag. Open your browser's developer console (right-click → Inspect → Console tab) to see the specific error message, then check the line it references.

Live Server won't open my file.

Make sure you're right-clicking directly on an .html file, not a folder. If the extension still doesn't respond, restart VS Code and try again.

My changes aren't showing up when I refresh.

Your browser may be showing a cached version of the page. Try a hard refresh: Ctrl+Shift+R on Windows/Linux, or Cmd+Shift+R on Mac.

Git says "fatal: not a git repository."

This means you ran a Git command outside a folder that's been initialized with git init. Navigate into your project folder first, then try again.

General Questions

Do I need to know how to code before starting?

No. Our Web Development and UI/UX tracks are built for complete beginners — Lesson 1.1 assumes zero prior experience.

What if I fall behind in a cohort?

Every cohort lesson is recorded, and your mentor will work with you directly to catch up. Falling behind occasionally is normal and expected.

Can I switch tracks after enrolling?

Yes, within the first two weeks of any track, at no additional cost. Just contact your admissions advisor.

Still stuck? Reach out through our Contact page — a real person will respond, not a bot.
