Introduction

Welcome to Dilse Code Academy's documentation hub. Whether you're a brand-new student setting up your workspace for the first time, or a returning student looking up a specific reference, this is where you'll find the practical, step-by-step information behind every course.

System Requirements

Before you begin, make sure your computer meets these minimum requirements:

Minimum system requirements
Requirement Minimum
Operating System Windows 10+, macOS 11+, or a modern Linux distribution
RAM 8GB minimum, 16GB recommended
Storage At least 5GB of free disk space
Internet A stable broadband connection for video lessons and live sessions
Browser The latest version of Chrome, Firefox, or Edge

Installation

Follow these steps in order to set up the tools you'll use throughout every track:

  1. Download and install Visual Studio Code, our recommended code editor, from the official VS Code website.
  2. Install Git, the version control system we use for all coursework submissions.
  3. Create a free GitHub account — this is where you'll submit projects and build your public portfolio.
  4. Install Node.js, required for the Web Development and Advanced JavaScript tracks specifically.
  5. Open VS Code and install the "Live Server" extension, which lets you preview your HTML files instantly in a browser.

Once your environment is set up, head to your first course to begin Lesson 1.1.
