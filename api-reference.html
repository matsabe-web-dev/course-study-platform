HTML Element Reference

A quick reference dictionary of the core semantic elements taught across our Web Development track, listed alphabetically.

  • Getting Started

  • Troubleshooting & FAQ
<article>

Represents self-contained content that would still make sense if distributed independently — a blog post, a news story, a single forum comment.

<article>
  <h2>Post Title</h2>
  <p>Post content.</p>
</article>
<aside>

Represents content tangentially related to the main content around it — a sidebar, a pull quote, or supplementary links.

<aside>
  <h3>Related Links</h3>
  <ul>...</ul>
</aside>
<details>

Creates a native, JavaScript-free expandable disclosure widget. Must be paired with a <summary> as its first child.

<details>
  <summary>Click to expand</summary>
  <p>Hidden content revealed on click.</p>
</details>
<figure>

Wraps self-contained media — an image, diagram, or code sample — that's referenced from the main text but doesn't need to sit at that exact point in the flow.

<figure>
  <img src="photo.jpg" alt="Description">
  <figcaption>Caption text.</figcaption>
</figure>
<nav>

Marks a section containing major navigation links. Not every group of links needs <nav> — reserve it for primary navigation blocks.

<nav aria-label="Main Navigation">
  <ul>...</ul>
</nav>
<section>

Groups a thematically related chunk of content, generally expected to have its own heading.

<section aria-labelledby="section-heading">
  <h2 id="section-heading">Title</h2>
</section>
